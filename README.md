# The Archive of Things

> Interactive things to explore, experiment with, and understand.

The Archive of Things is an open collection of interactive educational and experimental artifacts.

Sometimes you don't want to read an explanation or work through the equations.

You just want to see what happens.

Each artifact turns an idea, question, system, or theory into something you can interact with.

Change the variables. Move the sliders. Run the experiment. Break the assumptions. See the result.

Then, if you want to understand what happened, inspect the explanation or the source.

---

## How It Works

Every artifact is designed to be as simple and portable as possible.

### Play Online

Artifacts can be published through GitHub Pages.

Open one in your browser and start experimenting immediately.

No account.  
No installation.  
No complicated setup.

### Download

Where supported, an artifact can be downloaded as an HTML file and run locally.

Some artifacts are completely self-contained and work without an internet connection.

### Inspect

The source code is available.

You can see how the experiment works, understand the model, modify it, or build upon it.

---

## Online & Offline

Artifacts are labelled according to their requirements.

**ONLINE**

Requires an internet connection or online resources.

**OFFLINE**

Self-contained and designed to run locally without an internet connection.

**ONLINE + OFFLINE**

Can be used locally, while the online version may provide additional functionality.

The requirements of each artifact are stated explicitly.

## The Principle

The Archive is built around a simple loop:

> **Question → Prediction → Experiment → Observation → Understanding**

An artifact should not merely show you an answer.

It should give you something to manipulate.

You should be able to ask:

> What happens if I change this?

and immediately find out.

---

## A Different Way to Learn

You don't need to know all the mathematics before experimenting with a model.

You don't need to learn a programming language before testing an idea.

You don't need to read a 40-page explanation before touching the system.

Start with the experience.

Go deeper if you want.

An artifact may therefore contain several layers:

**Play**  
Interact with the model.

**Understand**  
See the explanation behind it.

**Inspect**  
Examine the assumptions and source code.

**Experiment**  
Change the model and test your own ideas.

---

## Connections

Some artifacts are connected to external works, research, articles, or publications.

Where there is a meaningful connection, the artifact contains a **wormhole** to the relevant material.

The connection works in both directions.

An interactive may lead you to an explanation.

An article may lead you to an interactive.

The Archive itself is independent of any particular publication.

## What Counts as an Artifact?

An artifact should generally be:

Interactive
Educational, experimental, exploratory, or explanatory
Built around a meaningful idea, question, or system
Understandable without unnecessary setup
Transparent about its assumptions
Functional rather than merely decorative

An artifact does not need to belong to a traditional academic subject.

It simply needs to give someone something worth exploring.

---

## Open by Design

The Archive is intended to remain transparent and inspectable.

The code is part of the artifact.

You are free to study how something works, modify it, experiment with it, and create your own versions, subject to the license of the individual artifact.

---

## Status

The Archive is an evolving collection.

New artifacts are added over time.

Some will be serious simulations.

Some will be visual explanations.

Some will be thought experiments.

Some will simply answer an interesting question.

There is no requirement for everything to look or behave the same.

The requirement is that there is something worth experiencing.
